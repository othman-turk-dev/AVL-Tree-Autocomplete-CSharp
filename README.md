# AVL Tree Autocomplete (C#)

A C# implementation of an AVL Tree featuring a simple autocomplete engine based on prefix searching.

This project was built to practice self-balancing binary search trees and demonstrate how efficient search structures can be used to implement autocomplete functionality.

---

## Features

- AVL Tree implementation from scratch
- Automatic tree balancing
- Insert, Delete, Search operation
- Exists check
- Tree visualization
- Prefix-based autocomplete
- Case-insensitive searching

---

## Implemented Algorithms

### AVL Tree

- Height calculation
- Balance factor
- Automatic rebalancing

Supported rotations:

- LL Rotation
- RR Rotation
- LR Rotation
- RL Rotation
